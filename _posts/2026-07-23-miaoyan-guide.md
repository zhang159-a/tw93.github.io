# 介绍

> Miaoyan（妙言）是一款 macOS 原生 Markdown 笔记与写作软件。

## 安装

1. Mac APP Store
   这个是需要付费的
2. Homebrew
   `brew install --cask miaoyan`
3. GitHub Releases
   下载 DMG

## 使用

1. 选好资料库
   可以选择 ICloud 实现同步，或者是坚果云
2. 认识主界面
   三栏布局

- 文件夹与资料库
- 笔记列表
- 编辑器或预览区

## 妙言 PPT

1. 按 `⌘⌥P` 启动妙言 PPT；也可以右键笔记选择“妙言 PPT”。
2. 演示中按 `Return` 打开或关闭幻灯片总览。
3. 按 `Esc` 退出。

只有包含 `---` 分隔符的文档才适合作为 PPT。

## 自动保存与版本历史

妙言会自动保存编辑内容。当前实现会在停止输入后稍作等待再写入磁盘，以避免每敲一个字都触发文件和云盘同步；切换窗口、关闭窗口或退出应用时也会刷新待保存内容。

需要立刻保存时按 `⌘S`。

查看历史版本：

- 选中笔记后按 `⌘⇧H`
- 或右键笔记，选择“版本历史”

版本历史是恢复误改的安全网，但不能替代正式备份。历史快照保存在 Mac 的 Application Support 目录，而不是你的 Markdown 资料库中；如果只复制资料库到另一台 Mac，这些历史快照不会自动跟过去。

# 图片上传

妙言可以使用以下服务，我之前一直用的都是 PicGo,我配置了两个图片存储的方式。

- uPic
- PicGo
- Picsee
- PicList

- 腾讯云 COS 这个如果访问量不大的话，一个月也就几毛钱
- Cloudflare 这个是有免费的额度，10GB，现在也够我用了

考虑到图片的隐私问题，我现在使用 Cloudflare ，因为有些照片在 腾讯云 过不了审，没法上传，但是腾讯云在国内的访问速度应该更加快一点。
