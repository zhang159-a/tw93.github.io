> Dia 是 The Browser Company 推出的 AI 浏览器。它保留正常浏览器的网页、标签页与登录能力，同时让你可以基于当前网页、已打开的标签页和已授权的服务提问、整理信息或生成草稿。

# 功能

## Chat

按 **`⌘E`** 打开 Dia Chat，然后提出一个具体的问题。
这个侧边栏 AI 功能，感觉比 GPT 的做得好，那个里面的字体没有办法调整，看起来很难受，但是这个 AI 功能估计之后就要收费了，现在还可以免费使用

## 侧边栏

真的很喜欢这个侧边栏的设计，从使用 Arc 开始， **`⌘S`**可以控制侧边栏，还可以设置侧边栏自动隐藏。

## 组织标签页

**Organized Tabs**：把相关页面归为一个有名字的组，例如“本周项目”或“旅行计划”。完成一个任务后，关闭无关标签，避免上下文越积越乱。

## Profiles 空间

**Profiles**：将“工作”和“个人”拆开。不同 Profile 可以使用各自的登录状态、标签页和颜色主题，适合同时使用公司账号与私人账号的人。

## Splits

**Splits**：把两个页面并排，例如左边视频会议、右边会议笔记；或左边需求文档、右边设计稿。Dia 会记住常用布局，重复会议时可快速恢复。

## Morning Brief

Dia 的 **Morning Brief** 会汇总日历、收件箱和关键链接；报告与上下文问答可将已打开页面、Slack、Notion、Calendar 等来源的信息整理起来。首次使用时，先只连接一个你最常用的服务并观察效果。

# 快捷键

| 快捷键                                       | 用途                               | 什么时候用                                                          |
| -------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------- |
| `⌘E`                                         | 打开 Dia Chat                      | 需要总结、比较或起草时。                                            |
| `⌘T`                                         | 新建标签页 / 打开 Command Bar      | 输入网址、搜索词，或输入 `new …` 创建已连接工具中的文档、Issue 等。 |
| 长按 `⌘T` 约一秒                             | 打开 Voice tab                     | 脑暴或口述提示词；`Esc` 取消，`Return` 停止录音，`⌘Return` 发送。   |
| `⌘S`                                         | 隐藏或显示 Tab Strip（Focus Mode） | 阅读、写作、演示时减少干扰。它不是“保存网页”。                      |
| `⌘⇧S`                                        | 在顶部标签栏与侧边栏之间切换       | 标签很多时切到 Sidebar；想看更大页面时切回 Topbar。                 |
| `Control + Tab`                              | 切到下一个标签页                   | 快速在最近的工作页面间移动。                                        |
| `Control + Shift + Tab`                      | 切到上一个标签页                   | 与上一项反向切换。                                                  |
| `⌘⇧C`                                        | 复制当前网址                       | 分享页面、粘贴到笔记或任务中。                                      |
| `Option` + 点击“新建标签页”按钮              | 在当前标签旁打开 Split             | 一侧保留原页面，另一侧开新页面进行对照。                            |
| `Control + 1`、`Control + 2`、`Control + 3`… | 快速切换 Profile                   | 在工作、个人、客户账号之间切换。                                    |
| `⌘⇧K`                                        | 关闭所有标签页                     | **高风险操作**；只在确认当前窗口无需保留页面时使用。                |

还有两个很实用的小技巧：双击标签页即可直接重命名；在标签页上 **Control-点击**（或触控板双指点按）打开菜单，可以看到操作对应的快捷键，且会显示你自定义后的版本。
