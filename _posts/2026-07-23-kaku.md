> [Kaku](https://kaku.fun/) 是一款只面向 macOS 的开源终端，基于 WezTerm 深度定制。

# 介绍

- 安装之后即可使用，不需要复杂的配置
- 标签页、分屏、会话恢复、深浅色切换
- JetBrains Mono 字体
- 命令补全、语法高亮和历史建议
- 集成 Lazygit,Yazi,Starship,Delta 等终端工具
- 内置 AI 助手，可以使用订阅或者是自定义的 AI 服务

# 安装

1. DMG
2. Homebrew `brew install tw93/tap/kakuku`

首次启动
第一次打开时，Kaku 会自动设置 Shell 环境。完成后运行：

```
kaku doctor
```

`kaku doctor` 会检查 Kaku 命令、`PATH`、Shell integration 和可选工具是否正常。以后遇到补全、`y`、AI 快捷命令或工具无法使用时，也应先运行它。

如果你希望重新执行初始化：

```
kaku init
```

初始化过程可以为 `zsh` 或 `fish` 配置 Kaku integration，并让你选择是否安装 Starship、Delta、Lazygit、Yazi 等可选工具。执行前留意终端中的确认提示。

# 常用快捷键

## 窗口和标签页

| 操作                     | 快捷键                                |
| ------------------------ | ------------------------------------- |
| 新建窗口                 | `Cmd + N`                             |
| 新建标签页               | `Cmd + T`                             |
| 切换到第 1 ～ 9 个标签页 | `Cmd + 1` ～ `Cmd + 9`                |
| 上一个 / 下一个标签页    | `Cmd + Shift + [` / `Cmd + Shift + ]` |
| 重新打开刚关闭的标签页   | `Cmd + Shift + T`                     |
| 关闭当前标签页           | `Cmd + Shift + W`                     |
| 全屏 / 退出全屏          | `Cmd + Ctrl + F`                      |
| 退出 Kaku                | `Cmd + Q`                             |

`Cmd + W` 是智能关闭：

- 有多个分屏时，先关闭当前分屏；
- 有多个标签页或窗口时，关闭当前标签页；
- 只剩一个标签页时，隐藏 Kaku。

双击标签标题可以给标签重命名。

## 分屏

| 操作                         | 快捷键                |
| ---------------------------- | --------------------- |
| 左右分屏                     | `Cmd + D`             |
| 上下分屏                     | `Cmd + Shift + D`     |
| 切换分屏方向                 | `Cmd + Shift + S`     |
| 在分屏之间移动焦点           | `Cmd + Opt + 方向键`  |
| 调整分屏大小                 | `Cmd + Ctrl + 方向键` |
| 放大 / 还原当前分屏          | `Cmd + Shift + Enter` |
| 向当前标签页所有分屏广播输入 | `Cmd + Opt + I`       |
| 向所有标签页广播输入         | `Cmd + Shift + I`     |

广播输入会把同一段键盘输入发送到多个终端。它适合对多个相同环境执行一致操作，但也容易误操作；开启后先确认目标分屏，再输入命令。

## 编辑、显示与鼠标

| 操作                    | 快捷键或手势                      |
| ----------------------- | --------------------------------- |
| 清屏并清除 scrollback   | `Cmd + K`                         |
| 增大 / 减小 / 重置字号  | `Cmd + =` / `Cmd + -` / `Cmd + 0` |
| 跳到上一个 / 下一个单词 | `Opt + ←` / `Opt + →`             |
| 跳到行首 / 行尾         | `Cmd + ←` / `Cmd + →`             |
| 删除到行首              | `Cmd + Backspace`                 |
| 删除前一个单词          | `Opt + Backspace`                 |
| 复制文字                | 鼠标选中后松开，默认自动复制      |
| 打开链接或文件路径      | `Cmd + 单击`                      |
| 在当前输入行移动光标    | `Opt + 单击`                      |
| 打开设置                | `Cmd + ,`                         |

# 工作流

一个常见的开发布局：

1. 在第一个分屏运行开发服务器；
2. 按 `Cmd + D` 新建第二个分屏，用于 Git、测试或普通命令；
3. 按 `Cmd + T` 新建标签页，用于 AI coding 工具；
4. 用 `Cmd + Opt + 方向键` 在分屏间移动；
5. 用 `Cmd + 1`、`Cmd + 2` 快速切换标签页。

Kaku 默认会让新窗口、新标签页和新分屏继承当前工作目录，并在重新启动后恢复之前的标签页、分屏和部分 scrollback。

需要手动恢复最近保存的窗口布局时，使用：
`Cmd + Opt + Shift + T`
也可以从菜单 `Shell > Restore Previous Window` 恢复。

# 命令补全和 Smart Tab

Kaku 默认加载命令补全、语法高亮和基于历史记录的灰色建议。当前默认的 Smart Tab 行为是：

1. 输入命令的一部分；
2. 如果右侧出现灰色建议，按 `Tab` 接受；
3. 没有建议时，`Tab` 回退为普通补全。

可以打开设置修改 Smart Tab：

```
kaku config
```

可选模式：

- `suggestion_first`：先接受灰色建议，默认值；
- `completion_first`：先显示普通补全列表；
- `off`：关闭 Smart Tab，恢复 Shell 原生行为。

# Kaku AI

AI 是可选功能。Kaku 本身不要求登录账号；只有启用 AI 时，才需要配置你选择的 AI 服务。

## 配置 AI

在 Kaku 中运行：

```
kaku ai
```

然后在设置界面中：

1. 启用 Kaku Assistant；
2. 选择 `Auth Type`：
   - API Key；
   - 已有的 Codex CLI / ChatGPT 登录；
3. 设置 `Simple Model`，用于自然语言生成命令、错误修复和轻量聊天；
4. 设置 `Deep Model`，用于主要聊天和工具调用；
5. 使用自定义服务时，再填写 OpenAI-compatible `Base URL` 和对应模型名。

不要把真实 API Key 写进教程、Shell 命令、Git 仓库或截图。优先在 `kaku ai` 的设置界面中输入。

## AI 聊天

按：

```
Cmd + L
```

打开内置 AI Chat。它可以流式显示 Markdown、代码块，并在你授权时使用项目文件、Shell、网页搜索和 memory 等工具。

在 Simple Model 和 Deep Model 不同时，可以在聊天面板内按 `Shift + Tab` 切换。

也可以从命令行进入同一套会话：

```
kaku chat
```

或者进行一次性提问：

```
kaku chat "解释当前项目的目录结构"
```

## 用自然语言生成命令

在提示符中输入 `#` 加一句描述，然后按 Enter：

```
# 查找最近 7 天修改过的文件
```

Kaku 会结合当前目录和 Git branch 生成命令，并把命令放回输入行。此时你应当先阅读，再按 Enter 执行。

## 自动建议失败命令的修复

当 Shell 命令以非零状态退出时，Kaku 可以把失败命令、退出码、当前目录和 Git branch 发送给已配置的模型，再显示修复建议。

按：

```
Cmd + Shift + E
```

只会把建议粘贴到提示符，不会自动执行。包括危险命令在内的所有建议，都应由你亲自检查后决定是否运行。

# Git、文件管理和远程文件

## Lazygit

在 Git 仓库中按：

```
Cmd + Shift + G
```

即可在当前分屏打开 Lazygit。若未安装，可以在 `kaku init` 中选择安装，或运行：

```
brew install lazygit
```

## Yazi

按：

```
Cmd + Shift + Y
```

在当前分屏打开 Yazi 文件管理器。也可以运行：

```
y
```

通过 `y` 启动时，退出 Yazi 后 Shell 会同步到你最后浏览的目录；直接运行 `yazi` 通常不会同步目录。

若 `y` 不可用或退出后目录没有变化，先运行：

```
kaku doctor
```

## SSH 和远程文件

普通 SSH 用法与其他终端相同，例如：

```
ssh user@example.com
```

Kaku `v0.15.0` 会识别 SSH、mosh、autossh 和 et 会话，在标签页中显示远程主机信息，并支持恢复 SSH 分屏。

当你已经位于 SSH 分屏中时，按：

```
Cmd + Shift + R
```

Kaku 会尝试使用 `sshfs` 把远程文件系统挂载到本机缓存目录，并在 Yazi 中打开。该功能要求：

- 已安装 macFUSE 和 sshfs；
- 远程主机已配置基于密钥的免密码认证。

可按官方文档安装依赖：

```
brew install macfuse sshfs
```

`Cmd + Shift + Y` 打开的是本地 Yazi；SSH 中浏览远程文件应使用 `Cmd + Shift + R`。

# 设置外观和行为

最省事的入口：

```
Cmd + ,
```

或者运行：

```
kaku config
```

Kaku 的终端配置文件位于：

```
~/.config/kaku/kaku.lua
```

AI 配置由 `kaku ai` 管理，位于：

```
~/.config/kaku/assistant.toml
```

通常只需要在生成的 `kaku.lua` 中修改少量 override。不要复制一整份网上的配置覆盖原文件。

## 配置示例

在 `kaku.lua` 中加载完 Kaku 默认配置后，只添加你确实需要的项目：

```
-- 调整字号
config.font_size = 16
​
-- 窗口透明度，1.0 为不透明
config.window_background_opacity = 0.95
​
-- 可选：启用滚动条
config.enable_scroll_bar = true
```

Kaku 默认跟随 macOS 自动切换深浅色。如需固定主题：

```
config.color_scheme = "Kaku Dark"
-- 或：
-- config.color_scheme = "Kaku Light"
```

修改快捷键时，只能向 `config.keys` 追加内容，不能用一个新 table 覆盖它，否则会清除 Kaku 默认快捷键。

## 选中即复制

Kaku 默认鼠标选中文字后自动复制。如果不喜欢：

```
config.copy_on_select = false
```

# 更新、检查和重置

运行：

```
kaku update
```

Homebrew 安装也可以使用：

```
brew upgrade tw93/tap/kakuku
```

Kaku 默认会在后台检查并下载新版本，但不会自行安装。安装更新会关闭窗口并停止其中正在运行的任务，因此先保存文件、停止服务，再确认更新。

## 诊断

`kaku doctor`

## 重置

`cp -R ~/.config/kaku ~/.config/kaku.backup`
`kaku reset`

这会移除 Kaku 管理的 Shell/tmux integration、部分状态和主题 managed blocks。官方 FAQ 说明，managed blocks 之外由用户编写的 Lua 会保留；但重置前仍建议备份。需要重新启用 Shell integration 时，再运行 `kaku init`。
