# 03 — 增加多标签组合筛选

**What to build:** 在文章索引的分类浏览基础上，让读者选择多个标签探索内容。多个标签扩大结果范围，分类与标签组合缩小范围；所有状态都能通过 URL 保存、分享和恢复。

**Blocked by:** 02 — 按分类浏览文章.

**Status:** ready-for-agent

- [ ] 文章索引展示已发布普通文章实际使用的全部标签，并显示每个标签对应的文章数量。
- [ ] 标签使用统一大小的可操作按钮，不使用按数量改变字号的标签云。
- [ ] 读者可以同时选择多个标签，多个标签之间采用 OR 匹配。
- [ ] 同时选择分类和标签时采用 `分类 AND（标签 A OR 标签 B）` 匹配。
- [ ] 多标签状态写入 `tags` query parameter；直接打开、刷新和复制 URL 都能恢复相同结果。
- [ ] 浏览器前进和后退会恢复对应的分类、标签和可见文章。
- [ ] 页面显示当前筛选条件和结果数量，并提供清除全部筛选的入口。
- [ ] 没有匹配文章时显示明确空状态，不回退到全部文章或保持空白。
- [ ] 文章详情显示全部标签，点击任一标签会进入已应用该标签的文章索引。
- [ ] 标签按钮在移动端可读、可点击、可换行，选中状态明确且页面没有水平溢出。
- [ ] production-equivalent build 与分类单选、标签多选、OR/AND 组合、深链接和移动端黑盒验证通过。
