# 02 — 按分类浏览文章

**What to build:** 让读者从顶部“文章”入口进入服务端生成的文章索引，看到全部已发布文章和四个固定分类，并能通过 URL 选择一个分类继续浏览。文章详情中的分类成为通往相同筛选结果的入口。

**Blocked by:** 01 — 建立安全的分类写作流程.

**Status:** ready-for-agent

- [ ] 顶部导航使用“文章”替换原 GitHub 入口并指向 `/articles/`；About、页脚、作者元数据和 SEO 中的 GitHub 链接保持不变。
- [ ] 文章索引由生产构建直接输出全部已发布普通文章，Weekly 不进入普通文章列表。
- [ ] 页面显示文章总数、“全部”和四个固定分类，并显示每个分类中的文章数量。
- [ ] 文章列表按发布时间倒序展示标题、日期、摘要、唯一分类和现有标签。
- [ ] 读者一次最多选择一个分类；选中分类后只显示该分类的文章，并能返回“全部”。
- [ ] 分类状态写入 `category` query parameter；直接打开或刷新带分类参数的 URL 会恢复相同结果。
- [ ] 文章详情显示唯一分类，点击后进入已应用该分类的文章索引。
- [ ] JavaScript 不可用时，构建后的 HTML 仍包含完整已发布文章列表。
- [ ] 分类控件、数量和文章列表在桌面与移动端均保持清晰，不破坏现有博客视觉语言。
- [ ] production-equivalent build 与分类浏览黑盒验证通过。
