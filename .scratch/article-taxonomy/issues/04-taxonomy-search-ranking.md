# 04 — 按分类和标签改进全站搜索

**What to build:** 让读者能通过标题、摘要、正文、分类或标签找到文章，并让主题元数据的明确命中优先于正文中的偶然提及，同时保持 Weekly 的现有搜索能力。

**Blocked by:** 01 — 建立安全的分类写作流程.

**Status:** ready-for-agent

- [ ] 构建生成的普通文章搜索数据包含标题、摘要、正文、唯一分类、标签、日期和内容类型。
- [ ] 搜索可以匹配文章标题、摘要、正文、分类和标签。
- [ ] 标题、分类和标签命中属于最高优先级，摘要命中次之，正文命中最低。
- [ ] 相同相关性下结果排序稳定且可预测，不会在相同输入下随机变化。
- [ ] 搜索结果显示有助于识别内容的分类和标签，并对 Front Matter 文本进行安全转义。
- [ ] Weekly 继续按标题、描述和正文参与搜索，并保持独立内容类型，不伪造普通文章分类或标签。
- [ ] 现有搜索的打开、关闭、输入防抖、键盘选择、加载、空结果和错误状态没有回归。
- [ ] 自动测试覆盖各字段命中、优先级排序、稳定排序、Weekly 搜索和恶意元数据转义。
- [ ] production-equivalent build 与公共搜索交互的黑盒验证通过。
